# 🛒 TechnOferta

![TechnOferta](https://github.com/user-attachments/assets/b67e336c-9fda-4d5d-a30e-53a2a244e8bd)

Proyecto desarrollado como entrega final del Bootcamp Full Stack de 4Geeks Academy.  
**TechnOferta** es una aplicación web que permite visualizar productos, acceder a sus detalles, agregar al carrito, y elegir entre distintos métodos de pago como tarjeta, efectivo (Abitab/RedPagos) y Mercado Pago, incluyendo también cálculo de impuestos y costos de envío.

---

## ✨ Características

- Visualización de productos con sus detalles
- Sistema de carrito de compras
- Filtrado de productos por nombre
- Métodos de pago integrados: tarjeta, efectivo, Mercado Pago
- Cálculo de impuestos y costos de envío
- Responsive: diseño adaptado a móviles y tablets
- API propia para productos

---

## 🚀 Tecnologías utilizadas

- 🔧 **Frontend:** React, Bootstrap, CSS
- 🔧 **Backend:** Python Flask, SQLAlchemy, PostgreSQL
- ☁️ **Despliegue:** Render (API) y Vercel (Frontend)
- 🧰 **Extras:** JWT para autenticación, Context API, Fetch, GitHub Actions

---

## 🔧 Instalación local

1. Cloná el repositorio:

```bash
git clone https://github.com/kiddopro/FinalProject4Geeks_G2.git
```

2. Ejecuta el Frontend:
   
```bash
cd FinalProject4Geeks_G2
cd front-end
npm install
npm run start
```

3. Ejecuta el Backend:

```bash
cd FinalProject4Geeks_G2/back-end
pip install -r requirements.txt
python3 src/main.py
```
